## Changes

Gemini live translation now requests verbatim original and target translation in one authenticated, structured audio request, reducing two sequential network round trips to one. Existing transcript-only provider methods remain available and tested. Both fields are required, complete responses only, with the existing endpoint, auth, response bounds, retry, cancellation and no-tools protections. Original and translated revisions still publish in order; speech receives only the translation. Empty original is treated as no audible speech.

Gemini groups short speech into at least 4-second chunks (10-second maximum; final short tail is retained). OpenAI keeps its existing endpoint timing. The pipeline FIFO accepts at most 30 seconds / 12 waiting chunks (~2.9 MB PCM), plus the bounded ingress and active chunk. This absorbs temporary slowness, but cannot guarantee zero skips when a provider remains slower than real time. Overload still counts skipped samples; buffer growth is bounded. More buffering can increase caption delay. Stop/cancel still clears pending work.

TTS trims only near-silent edge padding, retaining 40ms onset / 80ms release margins at 48k and preserving all internal pauses. Silent or very quiet clips are retained. Rate limits, PCM duration limits, recursive oversized-phrase splitting and gain remain unchanged. Technical logs add TRIMMED_SAMPLES, without recording speech text or audio.

Settings and Audio now expose Install offline voices, which opens Android's voice-data installer with a safe fallback to speech settings and a visible message if neither exists. Engine menus differ on Samsung/Google: speech settings → engine gear → install voice data → download target language. Restart translation afterwards. Downloads are managed by the installed engine; V2V does not bundle a voice model or silently use a cloud voice. Actual OEM intent behavior and listening quality require phone testing.

## Interface languages and captions

English, Traditional Chinese, Indonesian and Japanese UI catalogs cover main controls, history, audio, API-key forms, diagnostics controls, overlay controls, normal TTS setup errors and notification actions. UI locale is separate from translation languages. Choose Settings → Interface language; system language is supported, unsupported system locales fall back to English. Android 13+ uses persistent per-app LocaleManager and a locale-config; Android 10–12 use private preferences and configuration contexts for Activity/overlay service. Stop a session before switching. Some provider/backend technical errors remain their existing diagnostic messages. Transcripts and translations are never passed through UI localization.

Shared UI strings use stable Java UTF-16 hash keys. scripts/verify-locales.py checks complete keys across all 4 XML catalogs, format argument parity, nonempty labels and Kotlin/XML resource references before every CI build. Android aapt2 checks XML resource compilation. Resource shrinking is currently disabled; enabling it later requires keeping the dynamically keyed ui_* resources.

Caption size range is now 6–30sp; visible lines 2–10. Main settings and floating controls share these ranges; persisted settings accept 6sp and 10 lines. Existing defaults remain 18sp / 4 lines.
