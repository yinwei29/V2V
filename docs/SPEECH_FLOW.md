# 0.6.1-speech-flow

使用者提供的 0.6.0 Log 中，英文兩段翻譯產生 43 個 PCM 片段，印尼文兩段產生 35 個；繁中兩段為 9 個。舊規則最多 18 code points，且 6 字後遇到空格即斷句，因此拉丁語系常以單字或極短詞組個別合成，失去連續語調並增加合成間隔。

本版依目的語言分段：中文、日文沿用原短句策略；其他語言以完整句優先，長句上限 120 code points，優先在後半句的子句標點、其次在最後完整詞邊界分段。保留所有原文、空白及 Unicode code points，小數不當句點。單一超長詞仍有限制，避免無界合成。PCM 超過 10 秒時仍遞迴縮短，總佇列容量不變；不提高語速掩蓋斷句問題。

新增測試覆蓋英／印尼完整短句、長段落完整詞、中文日文策略保持、小數與超長詞、過長 PCM 重分段終止與無損。主程式及全部測試來源以快取 Kotlin／Compose compiler 編譯；完整 Android 建置、單元測試及 lint 由本版 CircleCI 執行。未在實體手機聽測，不宣稱已驗證不同離線語音引擎的實際停頓與音質。原始使用者 Log 不提交。

下載本版 CI Artifacts 的 V2V-0.6.1-speech-flow-debug.apk 更新，測試英文／印尼文連續段落並匯出新 Log。無新增 API Key 或手動設定要求。
