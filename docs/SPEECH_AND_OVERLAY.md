# 語音與浮窗預覽 · 0.3.1

先安裝同一 CircleCI 來源的新版，保留既有 Key 與設定。若簽章不相容，先匯出 Log；卸載會清除 Key，需重新輸入。

## 手機設定

1. 點「Android 文字轉語音設定」，確認預設引擎有已安裝的離線中文（台灣）聲線。缺少時本版不會偷偷改用網路聲線，會顯示錯誤並保留字幕；安裝／改引擎後停止再開始。
2. 點「設定浮動字幕權限」授予顯示在其他應用程式上層；返回主畫面，開始翻譯，再按「顯示浮動字幕／小圈圈」。已有權限時新工作階段會自動顯示。
3. 用有權存取的短句測試，確認原文、翻譯、中文播報。切換到其他 App，小圈圈與字幕應繼續。外部來源原聲不可控，本版不靜音其他 App。
4. 小圈圈點一下展開控制：暫停／恢復播報、字幕加寬／縮窄、閱讀模式、開主畫面、隱藏字幕、停止。圈圈拖曳後吸邊，字幕可在調整模式拖曳，位置與寬度保留。通知的「顯示字幕」可恢復隱藏視窗。
5. 混音頁可改播報開關／0.75–2語速（可自動追趕）、14–30sp字幕、2–6行、0–100%背景透明度。普通模式白字與黑色描邊不隨背景alpha變動。Android12+觸控穿透受系統安全限制，閱讀模式會將整個字幕視窗alpha降到系統允許上限，因此文字也略透明；小圈圈仍可恢復調整。
6. 戴耳機後拔掉，預期本 APP 播報立即暫停並清除待播音訊，字幕持續；接回後需自行確認恢復，不補播舊句。這是程式設計，OEM瞬間路由與斷線延遲仍待實測，沒有保證零外洩。
7. 停止後到診斷匯出 Log，附是否有聲、語音引擎名稱、浮窗權限、來源版本、耳機與重現步驟；不要附API Key。

## 實作與限制

真實PCM由合成回呼取得，PCM16的8–48k mono/stereo轉mono48k，交給原有50ms ramp／limiter／單一stereo AudioTrack。外部來源的原聲分支固定0，不重播擷取副本；本APP輸出不允許被擷取，擷取也排除本APP UID。防回灌與實體左右聲道仍需要實測。

離線語音的供應商／語音包依手機安裝引擎決定；無法初始化、沒有zh-TW、PCM格式不符、合成逾時或無法繼續分短的超長片段皆明示TTS錯誤，ASR／MT不因TTS失敗停止。字幕只在記憶體，語音僅處理final；停止／暫停／關閉播報清除舊queue。三段合計上限包含合成中、文字等候與PCM待播，PCM最多10秒。不能宣稱影片與譯音同步。

本版具字級、行數、背景alpha、描邊、拖曳、寬度、閱讀模式與持久化；完整色票、行距、自訂描邊寬度、無障礙互動與所有摺疊螢幕邊界仍需後續驗收／完善。裝置端TTS、防回灌、浮窗、旋轉、權限撤銷、藍牙、鎖屏皆NOT_TESTED_ON_DEVICE，不把JVM測試當成Android實測。


## 0.3.1 外部來源與漏播修正

優先操作：先在V2V勾雲端同意並開始其他App擷取，按系統授權；切至YouTube／Zoom／Google Meet。已授權時浮窗會隨工作階段出現，圈圈控制中可直接調基準語速與譯音增益，不用切回Activity。浮動控制清單可捲動，避免加上按鈕後超出摺疊手機螢幕。

每個final譯文拆為不超18個Unicode code point的短片語，優先標點／空白，不改寫內容；超10秒引擎音訊會再分短重試。第一個短句完成即可入PCM等待播放，之後逐句接續，不必等整段。PCM容量滿時等待釋出，不捨棄一整段正常譯文。語音排程仍最多3個翻譯段（包括合成中與待播），PCM最多10秒；持續發言快於最高速度時仍可能真正過載，會明示跳過並保留字幕。自動追趕按譯文長度／來源時長與積壓估算，請求速度最多2×，不代表引擎實際速度已測量，不能保證影片／字幕／播報同步。

外部來源只調V2V譯音音量與左右聲道，來源App原聲不變，不播放擷取副本。由V2V播放的WAV／測試來源保留完整混音。增益最高200%並經現有limiter；不代表音壓恰好兩倍。可手動降低媒體音量後補強V2V譯音，但這不是分App調整。Samsung也可手動嘗試官方Sound Assistant的Individual application volume，逐一測來源與機型，不假定它能處理Zoom／Meet通話串流；若擷取變靜音先恢復原聲音量。
